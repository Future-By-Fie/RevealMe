# Contributing

RevealMe is an open Future-by-Fie proof-of-concept.

Contributions should preserve the core principle: **meet before you reveal**.

For meaningful changes, explain:

1. What user problem the change addresses.
2. How it affects the reveal mechanic.
3. Any privacy or safety implications.
4. Whether the change is prototype-only or production-oriented.

Please do not add real personal data, private images or real genetic/identity datasets to the repository.
