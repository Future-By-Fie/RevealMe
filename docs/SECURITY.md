# RevealMe — Security

RevealMe changes the order in which identity is exposed, which makes access control central to the product.

## Core requirements for production

- Server-authoritative reveal state
- Strong authentication and session handling
- Private media storage
- Row-level access control
- Secure image processing
- Rate limiting and abuse prevention
- Auditability of sensitive reveal actions
- Account deletion and data export
- Protection against enumeration and scraping

The current repository is a prototype and does not claim production security.
