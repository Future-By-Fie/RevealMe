# RevealMe — Roadmap

## v0.1 — Proof of concept

**Built.** Demonstrate the interaction loop, reveal mechanic and core product idea with local/demo data.

## Next phase

- Harden the reveal state model
- Move sensitive state server-side
- Add real authentication
- Add private media storage
- Implement RLS/access policies
- Add safety and moderation flows
- Validate the interaction with real users
- Document findings

## Future

Explore production architecture, business model, platform distribution and integrations only after the core interaction proves useful.

RevealMe is intentionally not being positioned as an App Store-ready product yet.
